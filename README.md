# Cognitive-IPS

A modular, high-performance, and privacy-focused Intrusion Prevention System (IPS) built in Python. **Cognitive-IPS** combines kernel-level packet filtering via BPF, multi-scale temporal behavioral analysis (fast, slow, and stealth scans)[cite: 7], local AI triage via Ollama[cite: 3, 4], and instant, native mitigation through **`nftables`**.

---

## 🚀 Architecture

The project features a clean, decoupled architecture consisting of four core components:

1. **`sentinel.py` (Capture Layer):**
   * Efficient **IPv4 and IPv6** network traffic sniffing using `scapy`.
   * Leverages kernel-generated BPF filters to drop trusted traffic (whitelist and local network) before it consumes Python interpreter cycles[cite: 6].
   * Writes structured, compact logs using a `RotatingFileHandler`[cite: 6].

2. **`config.py` (Perimeter & Central Config):**
   * Single source of truth for thresholds, whitelist IPs, and trusted networks[cite: 4].
   * Auto-detection of host local IPs (`hostname -I`) to prevent self-inflicted DoS[cite: 4].
   * Intelligent IPv6 subnet aggregation into `/64` blocks to mitigate rotating IP scans[cite: 4].

3. **`audit.py` (Decision Engine & Dashboard):**
   * Continuously tails the log generated by Sentinel.
   * Performs behavioral analysis across **three simultaneous time scales**:
     * **1 s:** Detects fast, aggressive scans (`nmap -T4`/`-T5` style)[cite: 7].
     * **60 s:** Detects polite, moderate scans (`nmap -T2` style)[cite: 7].
     * **900 s (15 min):** Detects long-term stealth scans (`nmap -T1` style)[cite: 7].
   * Optional local LLM integration via Ollama (`qwen2.5-coder:3b`) for contextual triage of suspicious payloads with strict prompt-injection defense[cite: 3, 4].
   * Real-time interactive terminal dashboard built with `rich`.

4. **`firewall.py` (Native `nftables` Backend):**
   * Creates a dedicated table (`inet cognitive_ips`) with optimized sets for IPv4 and IPv6.
   * Hooks into `prerouting` at high priority (`-300` / raw), intercepting malicious packets **before** conntrack, NAT, and Docker container rules.
   * Utilizes **native kernel timeouts**: bans expire automatically without background cleanup routines in Python.

## ⚙️ Prerequisites & Dependencies

* **Operating System:** Linux (tested on WSL / native Linux environments with networking tools).
* **Interpreter:** Python 3.8+
* **Essential Python Packages:** `scapy`, `requests`, `rich`
* **System Tools:** `nftables` (`sudo apt install nftables`), `iproute2`

Install required Python dependencies:
```bash
pip install scapy requests rich

🛠️ Usage

Root privileges (root) are required to capture packets on the network interface and interact with the kernel firewall subsystem[cite: 5, 6].
1. Start Traffic Capture (sentinel.py)

In a dedicated terminal, start the collector pointing to your target interface (or omit to use the default route, optionally adding container interfaces like docker0):
Bash

sudo python3 sentinel.py --iface eth0

2. Start Audit & Mitigation Engine (audit.py)

    Dry-Run Mode (Default): Monitors, scores, and displays the real-time visual dashboard without modifying the actual firewall rules[cite: 3]:
    Bash

    sudo python3 audit.py

    Enforce Mode (--enforce): Applies live blocks directly to kernel nftables when risk thresholds are reached[cite: 3]:
    Bash

    sudo python3 audit.py --enforce

    Disable LLM Triage (Ollama): Run in a purely behavioral mode without local model queries:
    Bash

    sudo python3 audit.py --no-llm

🧪 Automated Tests
